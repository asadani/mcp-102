# 10 · Cross-system workflow

The release-note flow searches completed tasks and reads a knowledge resource.
The host composes them into a draft. It does not ask an MCP server to call
itself or hide an open-ended agent loop inside a tool.

Stable orchestration may move behind one task-shaped tool when doing so reduces
round trips and preserves identity, deadlines and errors. Keep reasoning in the
host unless server-owned reasoning is part of the product.
